# Restaurant Menu Display

**Source:** Trainer Notes, Week 3 component communication mini-project.

## Requirements

- [x] `RestaurantHeader`, `MenuItem`, `MenuCategory`, and `MenuApp` components.
- [x] Defaults, ratings, conditional descriptions and vegetarian/spicy tags.

- [x] Spread props, `RM0.00` formatting, category counts, and order callback feedback.

Run `npm install`, `npm test -- --run`, `npm run build`, or `npm run dev`.
