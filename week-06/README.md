# Week 6 - PostgreSQL, Routers, and Full-Stack Integration

## Exercises

- `01-postgresql-todo-api`: complete todo CRUD contract and PostgreSQL configuration.
- `02-window-routers`: importable left/right router exercise.
- `03-todos-books-api`: combined router application.
- `04-react-fastapi`: responsive book manager with CORS, extracted React component, external CSS, API client, and `category` enhancement.
- `postgresql-crud-api`: original student submission retained unchanged for traceability.

The PostgreSQL exercise requires local database settings. Copy `.env.example` to `.env`, replace the placeholder password, and load those environment variables before starting the application.

No database password is stored in this repository. Live PostgreSQL startup is an external verification checkpoint; deterministic service and contract tests are included.
